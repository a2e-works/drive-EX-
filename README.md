# Googleドライブ整理ツール（drive-EX）

`index.html` の1ファイルだけで動きます。サーバー側の処理はありません。
Googleへの通信は、ログインとドライブの操作（Google Drive API）だけです。

---

## 1. Google Cloud の準備（最初の1回だけ）

1. https://console.cloud.google.com/ で新しいプロジェクトを作る（名前は例：drive-seiri）
2. 「APIとサービス」→「ライブラリ」→ **Google Drive API** を有効にする
3. 「OAuth 同意画面」（Google Auth Platform）を設定
   - User Type：**外部**
   - アプリ名・サポートメールなど必須項目を入力
   - 「データアクセス」でスコープ **`https://www.googleapis.com/auth/drive`** を追加
   - 「対象（テストユーザー）」に、**このツールで使うGoogleアカウントを全部**追加
     （仕事用・個人用など、切り替えたいアカウントすべて）
   - 公開ステータスは **「テスト」のまま** でOK
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - アプリケーションの種類：**ウェブアプリケーション**
   - 承認済みの JavaScript 生成元：下の「2. 置き場所」で決めたURLの生成元を追加
     - GitHub Pages の場合：`https://a2e-works.github.io`
     - 自分のPCで開く場合：`http://localhost:8080`
     - 両方入れておいても構いません
   - 承認済みのリダイレクト URI：空でOK
5. 発行された **クライアントID**（…apps.googleusercontent.com）を控える
   ※ クライアントシークレットは使いません

## 2. 置き場所（どちらか）

ファイルを直接ダブルクリックして開いた状態（file://）では、Googleにログインできません。URLで開ける場所に置きます。

### A. GitHub Pages（おすすめ・スマホからも開ける）
1. a2e-works に新しいリポジトリ（例：drive-seiri）を作り、`index.html` を置いてpush
2. Settings → Pages → Source：Deploy from a branch → Branch：main /(root)
3. `https://a2e-works.github.io/drive-seiri/` で開ける
   - ページ自体は公開されますが、中にIDや鍵は入っていません。
     クライアントIDは開いたブラウザにだけ保存され、ログインできるのはテストユーザーに登録したアカウントだけです。

### B. 自分のPCだけで使う
`index.html` を置いたフォルダで、PowerShellから次を実行（Pythonが必要）

```
python -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開く。終わったらPowerShellで Ctrl+C。

## 3. 初回の使い方
1. 画面上の「初期設定」にクライアントIDを貼って「保存」
2. 「Googleでログイン」→ アカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら「続行」。自分で作ったものなので問題ありません
   - 権限の画面で **ドライブのチェックを必ず入れる**
3. 別のアカウントも使うときは「アカウントを追加」。右上のプルダウンで切り替えます

## 4. 機能
- 絞り込み（すべてAND）：ファイル名（含む語・除外語）、種類、更新日、作成日、サイズ、用途、フォルダ、オーナー
- ファイル名の指定方法（下記）
- 一覧の「用途」プルダウンで選ぶと、その場で保存
- チェックしたファイルに一括で：用途を付ける／外す、フォルダ移動、ゴミ箱へ
- 実行前に対象一覧の確認が出ます。ゴミ箱へ移したものは30日以内ならドライブのゴミ箱から戻せます
- 左ペインのフォルダツリー、PCとのやり取り（下記）
- 名前の一括変更、重複ファイルの検出、操作履歴と「元に戻す」、一覧のCSV保存（下記）

### 左ペイン：ドライブのフォルダツリー
- ▸ を押すと下のフォルダを開きます（開いたときに読み込みます）
- フォルダ名をクリックすると、そのフォルダの中身（直下のファイル）を右の一覧に表示します。このとき上の絞り込み条件も効きます
- クリックしたフォルダが「アップロード先」になります
- 一覧の行をツリーのフォルダへ**ドラッグ**すると、そのフォルダへ移動します（チェックした行があれば、それらをまとめて移動）
- フォルダを作ったり名前を変えたりしたあとは「↻ 更新」

### ドライブ → PC（PC版のChrome・Edgeのみ）
1. 左下「PC」の「フォルダを選ぶ」で、保存先のフォルダを選ぶ（初回は書き込みの許可を求められます）
2. 一覧でファイルにチェックを付けて
   - **PCへコピー**：PCに保存。ドライブ側はそのまま
   - **PCへ移動**：PCに保存し、**保存できたものだけ**ドライブのゴミ箱へ
- PCに同じ名前のファイルがあれば「名前 (1).pdf」のように番号を付けて保存します（上書きしません）
- Googleドキュメント・スプレッドシート・スライドは、Word・Excel・PowerPoint形式に変換して保存します（図形描画はPNG）。Googleフォームなどは保存できません
- Windowsのファイル名に使えない文字（`\ / : * ? " < > |`）は `_` に置き換えます
- PCのフォルダはページを開くたびに選び直しです

### PC → ドライブ
アップロード先は、ツリーで選んでいるフォルダです。次のどれでもアップロードできます。
- 左下「PC」の一覧でファイルにチェック →「選択をドライブへ」
- 「PC」の一覧のファイルを、ツリーのフォルダへドラッグ
- エクスプローラーからファイルを、ツリーのフォルダ、または「ここにファイルをドロップ」へドラッグ
- 「ファイルを選ぶ」ボタン（スマホでも使えます）

オプション
- **用途**：選んでおくと、アップロードと同時に用途を付けます
- **同名があればスキップ**：アップロード先に同じ名前のファイルがあれば送りません（外すと同名でも追加します。ドライブは同名ファイルを複数持てます）
- フォルダごとのアップロードには対応していません（ファイルだけ。フォルダをドロップした場合はスキップします）
- PC側のファイルは消しません（コピーのみ）

### 移動先の選び方・別アカウントへの移動
- 一覧の上の「**移動先を選ぶ…**」で選ぶ画面が開きます
  - フォルダ名で探すと、ログイン中の**全アカウント**から探し、「マイドライブ / 仕事 / 2026」のように**場所（フルパス）**とアカウントを表示します
  - 下のツリーから選ぶこともできます（▸で開く）
- 左の「ドライブ」には、ログイン中の全アカウントのフォルダツリーが並びます（👤 の行がアカウントの区切り）
  - 別アカウントのフォルダをクリックすると、そのアカウントに切り替えて中身を表示します
  - 一覧の行を別アカウントのフォルダへドラッグすると、そのアカウントへ送れます
- **別アカウントへは「コピー」か「移動（送れたものだけ元をゴミ箱へ）」を選べます**。ドライブの仕組み上、アカウントをまたぐ移動はできないため、ファイルを読み込んで送り先に作り直します
  - 引き継ぐもの：名前・**作成日・更新日**・用途
  - 引き継がないもの：共有設定・コメント・版の履歴
  - Googleドキュメント形式は、いったんOffice形式にして送り先でGoogle形式に戻します（フォームなどは送れません）。1ファイル1GBまで
  - 「元に戻す」で、送り先のコピーをゴミ箱へ移し、元のファイルも戻します（送り先のアカウントにもログインしておく必要があります）
- PCからアップロードしたファイルは、PCでの更新日時を引き継ぎます

### 空き容量
画面上部に、ログイン中のアカウントの空き容量を表示します。バーの色は **青＝ドライブ**、**黄＝ドライブのゴミ箱**、**灰＝Gmail・Googleフォトなど**（容量は3つで共有）。マウスを重ねると内訳が出ます。
- 使用率75%以上でオレンジ、90%以上で赤になります
- ゴミ箱へ移したファイルも、ゴミ箱を空にするまでは容量を使います
- アカウントを切り替えたとき、ゴミ箱へ移動・アップロード・元に戻すをしたときに更新します

### 一覧の表示
- 一覧はページごとに表示します（初期値25件。下の「表示件数」で50・100・200・すべてに変更でき、次回も残ります）
- 「ページ内を選択」でそのページの行を選択。続けて「検索結果すべて（N件）を選択」を押すと、全ページをまとめて選択できます
- **プレビュー**：PCではファイル名にマウスを重ねると小さなプレビューが出ます。各行の「👁」を押すと大きく表示し、← → キーで前後のファイルに移れます（Googleドキュメント形式・PDF・動画などはドライブのサムネイル、画像は元の画像を表示）

### 撮影してアップ（スマホ向け）
上の「📷 撮影してアップ」を押すと、スマホのカメラが起動します（PCではファイル選択になります）。
1. 撮影すると、確認画面に写真とアップロード先（ツリーで選んでいるフォルダ）が出ます
2. 用途を選んで「実行する」
3. 「📷 続けて撮る」で次の1枚へ

- ファイル名は `スキャン_年月日-時分秒.jpg` になります（あとで「名前を一括変更」で変えられます）
- 書類の自動切り抜き・傾き補正はしません（Googleドライブアプリの「スキャン」とは別の、普通のカメラです）

#### ドライブアプリの「スキャン」を使う設定
右上の「⚙」→「撮影ボタンの動作」で「Googleドライブアプリの『スキャン』を開く」を選ぶと、ボタンが「📄 ドライブでスキャン」に変わります。
1. 押すとGoogleドライブアプリが開きます（Android・iPhone）。アプリ右下の「スキャン」（カメラのボタン）で撮影・保存します。保存先のフォルダはアプリ側で選びます
2. このツールの画面に戻ると、ドライブアプリで新しく追加されたファイルを自動で探し、選択した状態で一覧に出します（保存の完了まで少し待つことがあります。出ないときは「もう一度確認」）
3. そのまま用途を付けたり、移動したりできます

- ドライブアプリは、ツールでログインしているのと同じアカウントで保存してください（別のアカウントで保存すると、このツールには出てきません）
- アプリを開くとき、スキャン画面まで直接は開けません。アプリのトップ画面が開くので、「スキャン」を1回押してください
- スマホのブラウザがメモリ節約のためにページを読み込み直した場合は、ログインし直しになります。そのときは「もう一度確認」の代わりに、更新日で絞り込んで探してください

### ファイル名の指定方法
- スペースで区切って複数の語を指定できます
  - 含む語：**すべて**に当てはまるファイルが残ります（AND）
  - 除外する語：**どれか1つ**に当てはまるファイルを外します
- `*` と `?` が使えます
  - `*` … 任意の文字列（0文字以上）
  - `?` … 任意の1文字
- `*` か `?` を含む語は、**ファイル名全体**と照合します（先頭・末尾の位置まで見ます）
- `*` も `?` も含まない語は、**部分一致**（ファイル名のどこかに入っていればOK）
- 英字の大文字・小文字は区別しません

| 入力 | 意味 | 当てはまる例 | 当てはまらない例 |
|---|---|---|---|
| `領収書` | 名前のどこかに「領収書」 | 2026_領収書_A.pdf | 請求書.pdf |
| `2026*.pdf` | 2026で始まり .pdf で終わる | 2026_領収書_A.pdf | 領収書_2026.pdf |
| `*.pdf` | .pdf で終わる | a.pdf | a.pdf.bak |
| `img_????.jpg` | img_ ＋ 4文字 ＋ .jpg | IMG_1234.JPG | IMG_12345.JPG |
| `領収書 2026*` | 「領収書」を含み、かつ2026で始まる | 2026_領収書.pdf | 領収書_2026.pdf |
| 除外に `*_old.*` | 名前が「_old」で終わるものを外す | memo_old.txt を除外 | old_memo.txt は残る |

注意：`2026*` は「2026で始まる」意味になります。「2026を含む」なら `2026` だけ（または `*2026*`）と入れてください。

### 名前を一括変更
一覧でファイルにチェック →「名前を一括変更」。変更前に全件のプレビューが出ます。

- **置換**：探す文字 → 置き換え後。「正規表現」にチェックすると正規表現が使えます（置き換え後に `$1` も使えます）
- **新しい名前**：次の記号を組み合わせます。拡張子（.pdf など）はそのまま残ります

| 記号 | 入るもの | 例 |
|---|---|---|
| `{名前}` | 今の名前（置換をしたなら置換後） | 領収書A |
| `{連番}` | 一覧の並び順の番号（開始・桁数を指定） | 001 |
| `{更新日}` `{作成日}` | ドライブ上の日付 YYYYMMDD | 20261015 |
| `{更新年月}` | YYYYMM | 202610 |
| `{用途}` | このツールで付けた用途 | 証憑 |
| `{フォルダ}` | 今いるフォルダ名 | 経費 |

例：`{作成日}_{名前}` → `20261015_領収書A.pdf`／`{用途}_{連番}` → `証憑_001.pdf`

プレビューで次を表示します（エラーの行は変更しません）
- 名前が空になる、255文字を超える → エラー
- 同じフォルダに同名ファイルができる → 注意（一覧に出ているファイルの範囲で確認）
- Windowsで使えない記号（`\ / : * ? " < > |`、末尾のピリオド・空白）→ 注意

### 重複を探す
検索結果の中から、**中身が同じファイル**（ドライブが持っている内容のハッシュ値とサイズが同じもの）を探します。
- 名前が違っても、中身が同じなら同じ組になります（「〇〇 (1).pdf」「コピー 〇〇」など）
- 各組で作成日がいちばん古い1件を残し、残りに自動でチェックを付けます。確認してから「ゴミ箱へ」などを押してください
- 調べる範囲は今の検索結果だけです。広く探すときは、フォルダ指定を外して検索してから押します
- Googleドキュメント形式（ハッシュ値がない）は比較できません
- 普通の一覧に戻すときは、もう一度「検索」

### 操作履歴と「元に戻す」
左下の「操作履歴」に、このツールで行った操作が残ります（アカウントごと、直近30回分、このブラウザに保存）。
「元に戻す」で、その回の操作をまとめて戻します。

| 操作 | 元に戻すと |
|---|---|
| ゴミ箱へ | ゴミ箱から元の場所に戻す（ゴミ箱を空にした後は戻せません） |
| PCへ移動 | ドライブのゴミ箱から戻す（PCに保存したファイルは残ります） |
| 移動（ボタン・ドラッグ） | 元のフォルダに戻す |
| 名前の変更 | 元の名前に戻す |
| 用途の設定・変更 | 元の用途に戻す |
| アップロード | アップロードしたファイルをゴミ箱へ |

- 古い操作を戻すとき、その後に同じファイルを操作していた場合は、その結果も上書きされます（確認画面に出ます）
- 「PCへコピー」はドライブ側を変えないので、履歴には残りません

### 一覧をCSV保存
今の一覧（ファイル名・用途・種類・サイズ・更新日時・作成日時・フォルダ・URL・ファイルID）をCSVで保存します。Excelでそのまま開けます。

## 5. 知っておくこと
- **ログインは約1時間で切れます。** 切れた後に操作すると自動で再ログインの小窓が出ます（ポップアップを許可しておいてください）
- ページを閉じたり再読み込みしたりすると、ログインはやり直しです（ログイン情報はブラウザに保存しない作りにしています）
- 用途はファイルのカスタムプロパティ（key: usage）に保存。ファイル名・中身は変わりません。アカウントをまたいでも、そのファイルについて回ります
- 用途の選択肢リストは、このブラウザに保存され、全アカウント共通です
- フォルダ指定は直下のファイルのみ。フォルダそのものは操作の対象外
- 1回の検索で調べるのは最大5,000件
- サイズ指定時は、Googleドキュメント形式（サイズなし）は対象外
- 「テスト」状態のOAuthは、テストユーザーに登録したアカウントしかログインできません。人に配る場合はGoogleの審査が必要になります

## 6. PowerToys・パソコン版ドライブとの違い

Microsoft PowerToys の **PowerRename** は、エクスプローラーで選んだファイルの名前を正規表現・連番・日付でまとめて変える道具です。
Googleドライブは、パソコン版ドライブ（G:ドライブ）を通せばエクスプローラーから操作できますが、そこには次のような制約があります。
このツールは、ドライブのAPIを直接使うことで、この部分を補います。

| 項目 | PowerToys（G:ドライブ経由） | このツール |
|---|---|---|
| 対象の選び方 | エクスプローラーで手で選ぶ。日付・サイズで絞り込む機能はない | 日付・サイズ・種類・名前（ワイルドカード）・用途・フォルダをANDで絞り込み |
| 反映のしかた | PCで変えた内容を、パソコン版ドライブが順番に同期。大量の変更の途中で再起動や回線切れがあると、反映漏れや重複ファイルが出ることがある | ドライブに直接反映。同期の待ち行列を通らない |
| Googleドキュメント形式 | G:ドライブ上はリンク用の小さなファイル（.gdoc／.gsheet）で、PCの別の場所へコピーできない場合がある | Word・Excel・PowerPoint形式に変換してPCに保存 |
| 重複ファイル | 探す機能はない | 中身のハッシュ値で検出 |
| 分類 | なし | 用途を付けて、絞り込み・名前に使える |
| 元に戻す | エクスプローラーの「元に戻す」で直前の操作のみ | 移動・名前変更・用途・ゴミ箱・アップロードを30回分、回ごとに戻せる |
| 複数アカウント | パソコン版ドライブ側で切り替え | 画面内で切り替え |
| 使える場所 | Windowsのみ | ブラウザ（PCとのやり取り以外はスマホでも可） |
| 不具合の報告 | 新しいバージョンで右クリックメニューに出ない不具合が報告され、未解決のまま（GitHub #48951） | — |

PowerToysの方が向いていること
- 正規表現の高度な機能（Boostライブラリ）、写真のExif情報（撮影日・カメラ名）を名前に使う
- PCの中だけのファイルの名前変更（ネットに出さずに済む）
- 初期設定がいらない（このツールはGoogle CloudでのクライアントID発行が必要）

参考
- PowerRename の機能：https://learn.microsoft.com/ja-jp/windows/powertoys/powerrename
- 右クリックメニューに出ない不具合：https://github.com/microsoft/PowerToys/issues/48951
- パソコン版ドライブで重複が出る仕組み：https://www.itgenius.com/blog/troubleshooting-google-drive-conflict-folders-why-duplicates-appear-and-how-to-fix-them/

## 更新履歴

バージョンは画面左上のタイトルの横に表示しています（マウスを重ねると更新日）。
直したときは、`index.html` の先頭近くにある `APP_VERSION` と `APP_DATE` を書き換えます。

| バージョン | 日付 | 内容 |
